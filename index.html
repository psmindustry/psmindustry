Análisis del Historial Git

Línea de tiempo detallada sobre la evolución del repositorio oficial.

Abril 2017 - Commit Inicial FOUNDATION

Creación oficial por Anuken. El primer commit ya presentaba una arquitectura robusta incluyendo módulos de IA, entidades, mundo y el ejecutable desktop inicial basado en el motor Arc (un fork avanzado de LibGDX).

Agosto 2018 - Versión Alpha & Mobile EXPANSION

Estabilización de las mecánicas core de recolección y logística. Se introdujo el soporte oficial para Android, demostrando la capacidad multiplataforma real del motor Arc mediante una abstracción total de inputs.

Septiembre 2019 - v5 & Steam Release MATURITY

Lanzamiento en Steam con integración de multijugador robusto (ArcNet), campañas mundiales y soporte para Mods vía Rhino JS. Este hito marcó la transición de un proyecto indie a un ecosistema de software completo.

CD + Jefe Sprint 2 (Karla Bedregal)

Flujo CD con GitHub Actions y gestión del Sprint 2.

assignment Tareas Asignadas

Como CD: extender el pipeline con .github/workflows/cd.yml. El workflow debe dispararse en cada merge a main y hacer dos cosas: generar un release automático en GitHub con el JAR compilado adjunto como asset descargable, y desplegar el sitio de GitHub Pages actualizando el branch gh-pages. Para el release puede usarse actions/create-release o la GitHub CLI (gh release create). Coordinar con P6 para que el path de deploy apunte al directorio correcto del HTML del sitio. Hacer un merge de demostración para disparar el workflow end-to-end. Tomar 3 capturas: pestaña Actions con cd.yml exitoso, detalle de los steps del run de CD, y la sección Releases del repo mostrando el release generado con el JAR adjunto.

Como Jefe Sprint 2: verificar que P4 y P6 entregaron sus partes. Tomar 2 capturas del kanban al cierre y de los Issues cerrados. Redactar la retrospectiva del Sprint 2 (2-3 párrafos). Total: 5 capturas + cd.yml + redacción de retrospectiva.
