1. Roles del Equipo (6 Integrantes)

Project Manager (Scrum Master)

Asignado a: [Nombre 1]

Coordina reuniones, verifica el cumplimiento del cronograma y mantiene la comunicación fluida del equipo.

Analista de Arquitectura

Asignado a: [Nombre 2]

Analiza patrones de diseño, estructura de módulos y diagramas de componentes (ej. dependencia de Arc engine).

Especialista en CI/CD y DevOps

Asignado a: [Nombre 3]

Revisa GitHub Actions, flujos de despliegue, manejo de dependencias (Gradle) y automatización.

Analista de Calidad (QA) y Testing

Asignado a: [Nombre 4]

Investiga la cobertura de pruebas, issues reportados, políticas de pull requests y métricas de deuda técnica.

Investigador de Metodologías

Asignado a: [Nombre 5]

Examina cómo la comunidad colabora (GitFlow, trunk-based), revisiones de código y el ciclo de vida de los issues.

Líder de Documentación

Asignado a: [Nombre 6]

Consolida los hallazgos, redacta el informe final y prepara la presentación académica y los recursos visuales.

2. Cronograma de Trabajo

Fase Tarea Responsable(s) Semana / Fecha Estado
Fase 1: Preparación Clonar repositorio, ejecutar herramientas (Gitingest, Cloc) y setup de dashboard. [Nombre 1, Nombre 6] Semana 1 Completado
Fase 2: Extracción Análisis de commits, branches, issues y PRs. Revisión de Gradle y workflows de GitHub. [Nombre 3, Nombre 5] Semana 2 En Progreso
Fase 3: Análisis Técnico Mapeo de arquitectura, ingeniería inversa, análisis de calidad y pruebas. [Nombre 2, Nombre 4] Semana 3 Pendiente
Fase 4: Consolidación Redacción del informe final, diagramación (Mermaid/UML) y preparación de la exposición. Todo el equipo Semana 4 Pendiente

3. Árbol del Proyecto (Mindustry Core Structure)

Mindustry/
├── .github/              # Flujos de trabajo de CI/CD (GitHub Actions)
├── annotations/          # Procesadores de anotaciones Java personalizadas
├── core/                 # ✨ Lógica principal del juego y entidades
│   ├── src/mindustry/
│   │   ├── ai/           # Inteligencia Artificial de las unidades
│   │   ├── core/         # Manejo de estado del juego, UI principal
│   │   ├── entities/     # Definición de unidades, balas, efectos
│   │   ├── gen/          # Código autogenerado
│   │   ├── maps/         # Generación y manejo de mapas
│   │   ├── net/          # Lógica de multijugador (redes)
│   │   └── world/        # Bloques, ambiente, físicas
├── desktop/              # Launcher y configuraciones para PC (Windows, Mac, Linux)
├── android/              # Configuraciones y empaquetado para Android
├── ios/                  # Configuraciones para iOS (RoboVM)
├── server/               # Servidor dedicado sin cabeza (Headless)
├── tools/                # Scripts y herramientas de desarrollo/construcción
├── build.gradle          # Configuración principal de dependencias (Gradle)
└── README.md             # Documentación principal del repositorio

* Este árbol es una abstracción. El framework base utilizado para el renderizado y utilidades es Arc, a menudo incluido como submódulo o dependencia.
